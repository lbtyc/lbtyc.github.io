SED

SED significa «Stream EDitor» (editor de flujos). Podemos pensar en SED como un objeto al cual le damos instrucciones y un flujo de datos (por ejemplo, un archivo), sobre el cual SED opera dichas instrucciones.

Las próximas lineas pretenden dar una muy breve introducción a SED, a través de simples ejemplos de uso. Pero, entendiendo la estructura de esos ejemplos, es posible luego construir instrucciones mas complejas. Por supuesto, usando Google uno puede encontrar bastante mas información sobre este extremadamente útil y potente editor.

1) Reemplazar la cadena ‘AAA’ por la cadena ‘BBB’ en el archivo (solo la primera ocurrencia en cada linea):

sed 's/AAA/BBB/' < archivo

2) Reemplazar la cadena ‘AAA’ por la cadena ‘BBB’ en el archivo (todas las ocurrencias):

 sed 's/AAA/BBB/g' < archivo            # g significa "Global"

3) Reemplazar la cadena ‘AAA’ por la cadena ‘BBB’ en el archivo, ignorando la capitalización (todas las ocurrencias):

 sed 's/AAA/BBB/gI' < file           # I significa "Ignore case"

4) Remover lineas conteniendo la cadena «AAA» del archivo:

sed '/AAA/ d' archivo > nuevoarchivo

5) Remover lineas conteniendo la cadena «AAA» del archivo, ignorando la capitalización:

 sed '/AAA/I d' archivo > nuevoarchivo       # d significa "Delete"

6) Remover lineas vacías del archivo:

 sed '/^$/ d' archivo > nuevoarchivo         # ^$ significa "linea vacía"

7) Remover todo entre las lineas 11 y el fin del archivo:

sed '11,$ d' < archivo                # $ significa "ultima linea" ​

8) Imprimir solo la linea 10 del archivo:

 sed -n '10p' archivo ​

9) Imprimir las lineas que contengan abc o ABC o aBc o ABc, etc:

 sed -n '/abc/I p' archivo > nuevoarchivo

Algunas aplicaciones de SED en bash

10) Remover lineas vacías (solo lineas vacías, no lineas con espacios) de todos los archivos cuyos nombres terminan en txt, y dar a los nuevos archivos el mismo nombre, pero con el prefijo «tmp»:

 for i in *.txt; do sed '/^$/d' tmp$i; done > nuevoarchivo

11) Remover la cadena ‘algo’ de todos los archivos cuyos nombres terminan en txt, y dar a los nuevos archivos el mismo nombre, pero con el prefijo «tmp»:

for i in *.txt; do sed -e 's/algo//' tmp$i;done
